        Two steps and this becomes useful

        This finds electives that fit around the classes you're already locked into. To do that it needs to know what those are.

        1. Import your enrolled classes. Takes about fifteen seconds. Paste from my.harvard, or one click if you have the extension.
        2. Set your background. The MDE rules branch on whether you have a SEAS or physical design background, so this changes what counts for credit.

        Everything stays in this browser. There is no account, no login, and your password, MFA code and cookies are never sent to this site.

        It does not approve anything. The MDE program office reviews every elective selection — treat this as a first pass, not a verdict.

        Import my enrolled classes

        my.harvard's course catalog is public, but your own schedule is not — it needs your session. Both routes below read it in your browser. Your password, MFA code and cookies never reach this site; only class titles, codes and meeting times do.

        One click extension detected

        The extension isn't installed on this browser. It's optional — the copy-paste route below needs no install and works everywhere. But if you'll be re-importing as your schedule changes, one click beats pasting.

        Download the extension Chrome / Edge · ~5 KB
        1. Unzip the download.
        2. Open chrome://extensions (paste it in the address bar — Chrome blocks links to it) and turn on Developer mode, top right.
        3. Click Load unpacked and pick the unzipped mde-electives-planner folder.
        4. Sign in to my.harvard, then reload this page.

        It asks for access to my.harvard.edu only. It reads that one calendar endpoint using the session you're already signed into and hands the result to this page — it has no server of its own and stores nothing.

        Copy and paste — no install needed

        1. Make sure you're signed in to my.harvard.
        2. Open this calendar link in a new tab. You'll see a wall of JSON.
        3. Select all of it (⌘A / Ctrl-A), copy, and paste it below.
